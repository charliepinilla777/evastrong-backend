Recordatorios por WhatsApp

Estado y configuración

El sistema envía automáticamente un mensaje de WhatsApp a cada usuaria 5 días antes de que venza su suscripción, todos los días a las 10:00 AM.

Para activarlo necesitas una cuenta de Twilio (gratuita para pruebas) y agregar estas variables en tu .env:

TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_WHATSAPP_FROM=whatsapp:+14155238886

Pasos para activar el Sandbox gratuito de Twilio:

  1. Crea cuenta en twilio.com
  2. Ve a Messaging → Try it out → Send a WhatsApp message
  3. Desde tu celular envía el mensaje indicado al +1 415 523 8886
  4. Tu número queda habilitado para recibir mensajes de prueba
  5. Agrega las credenciales en el .env y reinicia el servidor

Enviar mensaje de prueba

Ingresa un número habilitado en el sandbox de Twilio para probar que todo funciona.
